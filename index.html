Aktivitas 1 - Prediksi

let a = 10;
let b = 5;
console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
Operasi Prediksi Hasil Sebenarnya
a + b 15 15
a - b 5 5
a * b 50 50
a / b 2 2
Apakah prediksi kamu benar?

Ya

Mengapa?

Karena operasi aritmatika dasar yang dilakukan sesuai dengan aturan matematika umum di JavaScript.

Aktivitas 2 - Eksperimen

let a = 20;
let b = 4;
console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
console.log(a % b);
Prediksi & Hasil:

a + b = 24 | a - b = 16 | a * b = 80 | a / b = 5 | a % b = 0

Apa yang kamu temukan?

Operator % (modulo) digunakan untuk menghasilkan sisa hasil bagi. Karena 20 habis dibagi 4, hasilnya adalah 0.

Aktivitas 6 - Think Pair Share

THINK: Mengapa membutuhkan variable total?

Variabel total dibutuhkan untuk menyimpan hasil perhitungan perkalian harga dan jumlah secara tersentralisasi, sehingga mempermudah pemanggilan ulang data total belanja jika diperlukan kembali di bagian kode lainnya.

Aktivitas 8 - Debugging

Kode Awal dengan Kesalahan:

let harga = 5000;
let jumlah = 3;
let total = harga harga jumlah; // Error pada baris ini
console.log(total harga);
Kesalahan:

Penulisan sintaks pada perhitungan total tidak valid karena ada pengulangan kata harga tanpa operator yang jelas, serta penulisan console.log(total harga) kekurangan pemisah atau operator penggabungan (string concatenation).

Perbaikan Kode:
let harga = 5000;
let jumlah = 3;
let total = harga * jumlah;
console.log(total);

C. BAHAN AJAR

1. Mengingat Variable

Variable adalah tempat untuk menyimpan data.

let nama = "Budi";

let nilai = 85;

2. Input - Process - Output

INPUT → PROCESS → OUTPUT

let harga = 5000;
let jumlah = 3;
let total = harga * jumlah;
console.log(total);

3. Output dengan console.log()

console.log("Halo");
let nama = "Budi";
console.log(nama);
console.log("Nama saya adalah", nama);

4. Input dengan prompt()

let nama = prompt("Masukkan nama:");
console.log(nama);

Alur: Pengguna mengetik → prompt() → variable → console.log()

5. Operator Aritmatika

Operator Fungsi Contoh Hasil
+ Penjumlahan 10 + 5 15
- Pengurangan 10 - 5 5
* Perkalian 10 * 5 50
/ Pembagian 10 / 5 2
% Sisa pembagian (Modulo) 10 % 3 1

9. Catatan tentang prompt()

Hasil prompt() secara umum diterima sebagai teks/string. Untuk mengubahnya menjadi angka dapat digunakan Number().

let angka = Number(prompt("Masukkan angka:"));
