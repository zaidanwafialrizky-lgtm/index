DApersepsi

Bayangkan kamu sedang membuat aplikasi data siswa. Program perlu mengetahui: nama siswa, kelas, umur, nilai, jurusan.

Contohnya:

Nama siswa = "Budi"
Kelas = "XI RPL 1"
Umur = 16
Nilai = 85

Menurutmu, bagaimana cara menyimpan informasi tersebut di dalam program? Tuliskan dugaanmu:

JawabanInformasi tersebut disimpan menggunakan variable, yaitu tempat penyimpanan data yang diberi nama. Misalnya nama berisi "Budi", umur berisi 16, dan nilai berisi 85, sehingga data bisa dipakai kembali kapan saja oleh program.

EAktivitas 1 – Mengamati

Perhatikan kode berikut:

let nama = "Budi";
let umur = 16;
let nilai = 85;

console.log(nama);
console.log(umur);
console.log(nilai);

Jalankan kode tersebut menggunakan browser.

Pertanyaan

1. Apa yang ditampilkan pada Console?

JawabanConsole menampilkan tiga baris: Budi, 16, dan 85.

2. Menurutmu, apa fungsi nama, umur, dan nilai?

JawabanKetiganya adalah variable, yaitu tempat menyimpan data: nama menyimpan "Budi", umur menyimpan 16, dan nilai menyimpan 85.

3. Apa yang terjadi jika kode berikut dijalankan?

console.log(nama);
JawabanJika variable nama sudah dibuat sebelumnya, Console menampilkan isinya, yaitu Budi. Jika variable belum dibuat, muncul error ReferenceError: nama is not defined.

4. Menurut dugaanmu, apa yang dimaksud dengan variable?

JawabanVariable adalah tempat menyimpan data yang diberi nama, agar data tersebut dapat digunakan kembali oleh program.

FAktivitas 2 – Mengenal Variable

1. Apa itu Variable?

Variable dapat dianggap sebagai tempat untuk menyimpan sebuah data agar data tersebut dapat digunakan kembali oleh program.

Contoh:

let nama = "Andi";

Dapat dibayangkan seperti:

      nama
┌──────────────┐
│    "Andi"    │
└──────────────┘

Pada kode let nama = "Andi"; terdapat:

BagianFungsi
letMembuat variable
namaNama variable
=Memberikan nilai
"Andi"Nilai yang disimpan

GAktivitas 3 – Praktik Membuat Variable

Buat file: variable.html. Kemudian masukkan kode berikut:

<!DOCTYPE html>
<html>
<head>
  <title>Belajar Variable</title>
</head>
<body>
  <script>
    let nama = "Budi";
    let kelas = "XI RPL 1";
    let umur = 16;

    console.log(nama);
    console.log(kelas);
    console.log(umur);
  </script>
</body>
</html>

Buka file tersebut menggunakan browser. Kemudian buka: Klik kanan → Inspect → Console.

Hasil Pengamatan

Tuliskan hasil yang muncul pada Console.

JawabanNama : Budi
Kelas : XI RPL 1
Umur : 16

HAktivitas 4 – Eksperimen

Sekarang ubahlah program sebelumnya. Ubah let nama = "Budi"; menjadi nama kamu sendiri. Contoh: let nama = "Asep";

Kemudian ubah juga:

let kelas = "XI RPL 1";
let umur = 16;

sesuai data kamu.

Contoh kode setelah diubah
let nama = "Zaidan Wafi Al Rizky";
let kelas = "X PPLG 2";
let umur = 16; // ganti sesuai umurmu

Pertanyaan

1. Apakah hasil pada Console berubah?

JawabanYa, hasil pada Console berubah menjadi data yang baru: nama, kelas, dan umur milik saya.

2. Bagian kode mana yang kamu ubah?

JawabanNilai yang ada di sebelah kanan tanda sama dengan (=), yaitu isi "Budi", "XI RPL 1", dan 16. Nama variable dan let tidak diubah.

3. Mengapa program dapat menampilkan data yang baru?

JawabanKarena console.log() menampilkan nilai yang tersimpan di dalam variable. Saat nilai variable diganti, data yang ditampilkan ikut berubah.

JAktivitas 6 – Mengenal let dan const

Perhatikan kode berikut:

let umur = 16;
umur = 17;
console.log(umur);

Jalankan program tersebut. Hasil:

Jawaban17. Nilai umur berhasil diganti dari 16 menjadi 17.

Sekarang coba:

const nama = "Budi";
nama = "Andi";
console.log(nama);

Apa yang terjadi?

JawabanTerjadi error: TypeError: Assignment to constant variable. Nilai const tidak bisa diubah, sehingga console.log tidak sampai dijalankan.

Kesimpulan Sementara

Lengkapi tabel berikut.

KeywordNilai dapat diubah?Kegunaan sederhana
letYaUntuk data yang masih mungkin berubah
constTidakUntuk data yang tidak perlu diubah

Ingat! Gunakan let untuk data yang masih mungkin berubah. Contoh:

let nilai = 80;
nilai = 90;

Gunakan const untuk data yang tidak perlu diubah. Contoh:

const namaSekolah = "SMKN 1 Garut";

KAktivitas 7 – Aturan Penamaan Variable

Perhatikan nama variable berikut:

let nama;
let namaSiswa;
let nama_siswa;
let umur2;

Beberapa aturan dasar:

Diperbolehkan:

let nama;
let namaSiswa;
let nama_siswa;
let nilai1;

Tidak diperbolehkan:

let 1nama;
let nama siswa;
let nama-siswa;

Perhatikan juga: JavaScript membedakan huruf besar dan kecil.

let nama = "Andi";
console.log(nama);

berbeda dengan:

console.log(Nama);
