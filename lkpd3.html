C. AKTIVITAS 1: EKSPERIMEN 10 + 20

Prediksi hasil sebelum menjalankan kode. Jalankan kode dan amati. Simpan file sebagai lkpd_string_number_nama.js.

Kode Eksperimen:

let a = "10";
let b = "20";
console.log(a + b);

Pertanyaan & Jawaban:

  • Apa output program? Outputnya adalah 1020.
  • Mengapa hasil tersebut terjadi? Karena variabel a dan b bertipe data String (teks). Operator + pada String berfungsi untuk menggabungkan teks (konkatenasi), bukan melakukan penjumlahan matematika.
  • Apakah a dan b bertipe Number? Tidak, keduanya bertipe String karena nilainya diapit oleh tanda petik (" ").
  • Uji sekarang. Apakah prediksimu benar? Jelaskan: Ya, benar. Program menghasilkan 1020 karena terjadi penggabungan dua teks String.

D. AKTIVITAS 2: MENEMUKAN TIPE DATA

Kode yang dijalankan:

let nama = "Zaidan wafi al rizky";
let umur = 15;
console.log(typeof nama);
console.log(typeof umur);
Variabel Prediksi Hasil typeof Kesimpulan
nama string string Variabel nama bernilai teks.
umur number number Variabel umur bernilai angka.

Temuan: Apa perbedaan String dan Number berdasarkan eksperimenmu?

Jawaban: String adalah tipe data berupa teks yang diapit tanda petik, jika dioperasikan dengan tanda + akan digabungkan. Sedangkan Number adalah tipe data berupa angka tanpa tanda petik yang dapat dioperasikan dengan perhitungan matematika seperti biasa.

E. AKTIVITAS 3: KONVERSI STRING MENJADI NUMBER

Perbaiki program agar menghasilkan 30. Gunakan Number():

    let a = "10";
    let b = "20";
    let hasil = Number(a) + Number(b);
    console.log(hasil);

Catat hasil program: Output program setelah perbaikan adalah 30 karena variabel a dan b telah dikonversi dari String menjadi Number sebelum dijumlahkan.

F. AKTIVITAS 4: PROGRAM KASIR SEDERHANA

Program meminta harga barang dan jumlah barang melalui prompt(), mengubah keduanya menjadi Number, lalu menghitung total harga.

    let jumlah = Number(prompt("Masukkan jumlah: "));

G. TANTANGAN: PROGRAM HITUNG NILAI

Buat program dengan input nilai tugas, UTS, dan UAS. Konversikan semua input menggunakan Number(), lalu hitung rata-rata dengan rumus (tugas + UTS + UAS) / 3.

Algoritma saya:

  1. Mengambil input nilai tugas dari pengguna menggunakan prompt() dan mengonversinya ke Number dengan Number().
  2. Mengambil input nilai UTS dan UAS dari pengguna dengan cara yang sama (mengonversi ke Number).
  3. Menghitung nilai rata-rata menggunakan rumus: let rataRata = (tugas + UTS + UAS) / 3;
  4. Menampilkan hasil perhitungan rata-rata ke konsol menggunakan console.log().

H. THINK PAIR SHARE

Pertanyaan Jawaban
Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung? Karena fungsi prompt() selalu mengembalikan nilai bernilai tipe data String, sehingga jika dilakukan penjumlahan akan digabung (konkatenasi) dan bukan dijumlahkan secara matematika.
Apa perbedaan "10" dengan 10? "10" bertipe data String (teks), sedangkan 10 bertipe data Number (angka).
Apa yang terjadi jika lupa Number()? Hasil penjumlahan angka akan salah karena dibaca sebagai penggabungan teks (misal 10 + 20 menjadi 1020).

Pair: Bandingkan jawaban dengan teman. Apakah sama? Mengapa bisa berbeda?
Jawaban: Memiliki kesamaan dalam konsep, namun perbedaan cara penyampaian kata-kata.

Share: Sampaikan satu temuan penting kepada kelas.
Temuan: Selalu konversi input dari prompt() ke Number jika ingin melakukan operasi matematika.
